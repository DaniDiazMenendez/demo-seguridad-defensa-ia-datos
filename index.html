Objetivo: acelerar triage, explicar riesgo en lenguaje ejecutivo y preservar datos sensibles con Purview.

Incidente: phishing con movimiento lateral

Severidad alta Usuario comprometido, endpoint con ejecución sospechosa y acceso a repositorio con datos clasificados.

Security Copilot

Seleccioná un prompt para ver cómo la IA ayuda a explicar, evaluar impacto y sugerir respuesta.

Respuesta recomendada

  • 1Contener identidad
    Revocar sesiones, resetear credenciales y bloquear inicio de sesión riesgoso.
  • 2Aislar endpoint
    Usar Defender para aislar NB-FIN-042 y recolectar paquete forense.
  • 3Bloquear IoCs
    Agregar URL, hash y dominio de phishing a indicadores de bloqueo.
  • 4Revisar datos sensibles
    Validar con Purview si hubo acceso a información PII o financiera.
  • 5Comunicar y cerrar
    Documentar impacto, acciones y recomendaciones para comité de riesgo.
