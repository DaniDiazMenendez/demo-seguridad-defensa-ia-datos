# Demo: Defensa con IA y protección de datos

Industria: Servicios Financieros  
Escenario: Seguridad y cumplimiento  
Solución Microsoft: Security Copilot + Microsoft Defender + Purview  
Outcome esperado: Respuesta a incidentes más rápida y datos protegidos.

## Incluye

- Incidente de phishing con movimiento lateral.
- Dos perfiles de demo: Vista Analista SOC y Vista Ejecutiva.
- Cola de incidentes, entidades, línea de tiempo y prompts para Security Copilot.
- Resumen ejecutivo, mapa de impacto y decisiones para comité.
- Prompts en español para explicación, impacto, respuesta y comunicación ejecutiva.
- Guion de demo.

## Nota técnica

El sitio es una demo frontend para GitHub Pages. Las respuestas están precargadas para mostrar el flujo de valor esperado.
